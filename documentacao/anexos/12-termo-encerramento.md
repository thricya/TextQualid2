# 12 APÊNDICE B — TERMO DE ENCERRAMENTO DO PROJETO

## B.1 Identificação do Projeto

**Nome:** TextQualid2 — Sistema de Gerenciamento de Solicitações Acadêmicas.

**Instituição:** Instituição Alfa (fictícia).

**Disciplina:** Gestão e Qualidade de Software.

**Tipo:** Projeto acadêmico de desenvolvimento e avaliação da qualidade de software.

## B.2 Objetivo do Encerramento

Este documento tem como finalidade registrar o encerramento do desenvolvimento acadêmico do projeto TextQualid2, apresentando as atividades realizadas, os resultados alcançados, os testes executados e as limitações identificadas durante sua execução.

## B.3 Atividades Realizadas

Durante o desenvolvimento do projeto, foram realizadas as seguintes atividades:

- Definição do problema e dos objetivos do sistema.
- Levantamento e organização dos requisitos funcionais e não funcionais.
- Planejamento da estrutura e das funcionalidades do protótipo.
- Desenvolvimento do frontend com HTML5, CSS3 e JavaScript.
- Implementação do backend utilizando C# e ASP.NET Core com .NET 10.
- Criação e integração da API REST.
- Configuração do banco de dados SQLite.
- Utilização do Entity Framework Core para acesso e persistência dos dados.
- Implementação do cadastro e da consulta de solicitações por protocolo.
- Desenvolvimento do painel administrativo para visualização das solicitações.
- Implementação da visualização dos detalhes das solicitações.
- Implementação da atualização de status e do registro de observações.
- Criação de projetos de testes automatizados utilizando NUnit e xUnit.net.
- Execução de verificações manuais das funcionalidades no navegador.
- Execução e análise dos testes automatizados da camada de serviços.
- Elaboração da documentação acadêmica do projeto.

## B.4 Resultados Alcançados

O projeto resultou em um protótipo funcional de gerenciamento de solicitações acadêmicas, com as seguintes funcionalidades:

- Cadastro de solicitações.
- Geração de protocolos individuais.
- Consulta de solicitações por protocolo.
- Listagem das solicitações no painel administrativo.
- Visualização dos detalhes dos registros.
- Atualização de status.
- Registro de observações.
- Armazenamento persistente dos dados no banco SQLite.

Na etapa de automação de testes, foram desenvolvidos três casos de teste utilizando NUnit e os mesmos três cenários utilizando xUnit.net.

Os resultados obtidos foram:

| Framework | Testes executados | Aprovados | Reprovados |
|---|---:|---:|---:|
| NUnit | 3 | 3 | 0 |
| xUnit.net | 3 | 3 | 0 |
| **Total** | **6** | **6** | **0** |

Todos os seis testes automatizados foram aprovados, sem falhas ou testes ignorados, correspondendo a um percentual de aprovação de 100% nos cenários avaliados.

Além disso, as verificações manuais permitiram observar o funcionamento das principais operações do sistema, incluindo cadastro, consulta, visualização de detalhes e atualização das solicitações.

## B.5 Limitações e Melhorias Futuras

Apesar das funcionalidades implementadas, o TextQualid2 permanece como um protótipo acadêmico. Foram identificadas oportunidades de melhoria para versões futuras:

- Implementar autenticação de usuários.
- Criar controle de acesso para estudantes e funcionários.
- Desenvolver notificações automáticas.
- Ampliar as validações das informações.
- Implementar testes automatizados para os endpoints da API.
- Realizar testes adicionais de segurança, desempenho e usabilidade.
- Avaliar a implantação em um ambiente de produção.

## B.6 Lições Aprendidas

O desenvolvimento do TextQualid2 proporcionou aos integrantes do grupo a oportunidade de aplicar conhecimentos de programação, integração de sistemas, organização de requisitos, documentação e testes de software.

A utilização de C#, ASP.NET Core, Entity Framework Core e SQLite permitiu trabalhar com tecnologias do ecossistema .NET na construção de uma aplicação web.

A implementação dos testes com NUnit e xUnit.net também possibilitou compreender diferentes formas de organizar e executar testes automatizados, além de comparar os resultados dos dois frameworks em cenários equivalentes.

O projeto reforçou a importância do planejamento, da documentação e das práticas de Garantia e Controle da Qualidade durante o ciclo de desenvolvimento de software.

## B.7 Declaração de Encerramento

Com a implementação das principais funcionalidades previstas para o protótipo, a execução dos testes automatizados planejados, a realização das verificações manuais e a elaboração da documentação acadêmica, registra-se o encerramento das atividades de desenvolvimento do projeto TextQualid2 para fins da disciplina de Gestão e Qualidade de Software.

O encerramento refere-se à entrega acadêmica do protótipo e à avaliação dos cenários implementados, não representando a implantação de um sistema em ambiente de produção.
