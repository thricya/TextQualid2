# 2 OBJETIVOS

## 2.1 Objetivo geral

Desenvolver e avaliar uma adaptação do sistema de gerenciamento de solicitações acadêmicas TextQualid, denominada TextQualid2, utilizando C# e ASP.NET Core, com foco na aplicação prática de testes automatizados por meio dos frameworks NUnit e xUnit.net, a fim de compreender suas características e contribuições para a qualidade de software.

## 2.2 Objetivos específicos

- Identificar as necessidades relacionadas ao gerenciamento de solicitações acadêmicas no cenário proposto.
- Desenvolver uma interface que permita aos estudantes registrar solicitações e consultar seu andamento por meio de um protocolo.
- Implementar uma API REST utilizando C# e ASP.NET Core para processar e gerenciar as informações das solicitações.
- Desenvolver um painel administrativo para visualizar as solicitações cadastradas e seus respectivos detalhes.
- Permitir a atualização do status das solicitações e o registro de observações pela equipe responsável.
- Utilizar SQLite e Entity Framework Core para armazenar e gerenciar as informações, garantindo sua persistência.
- Compreender os conceitos de testes automatizados e sua importância para a qualidade de software.
- Implementar testes automatizados utilizando os frameworks NUnit e xUnit.net em projetos de teste separados.
- Verificar o funcionamento das principais operações do serviço de solicitações, incluindo cadastro, busca por identificador e atualização de status.
- Executar os testes automatizados e analisar os resultados obtidos com cada framework.
- Comparar as características, os recursos, as vantagens e as limitações do NUnit e do xUnit.net.
- Avaliar a contribuição dos testes automatizados para a confiabilidade e a manutenção do sistema.
